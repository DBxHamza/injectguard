Defense in depth

How it works — five layers

Each layer is cheaper and harder to fool than the model it protects. Content is screened before the agent reads it; any outbound action is screened again before it runs.

Content firewall — screens everything the agent reads
L1

Hidden & obfuscated content

Extracts what a human never sees: display:none, white-on-white, font-size:0, off-screen text, HTML comments, alt/aria attributes, zero-width & bidi characters, and base64 blobs (decoded and re-scanned). Hidden text that contains instructions is the single strongest signal.

L2

Weighted pattern rules

Offset-mapped regex over a normalized copy, so zero-width evasion still reports exact spans. Categories: override · fake-system · exfiltration · markdown-exfil · tool-abuse · concealment — in English, Urdu and Roman Urdu, with benign dampeners so recipes and docs stay quiet.

L3

Local LLM classifier (cascaded)

A local qwen3:4b via Ollama judges intent on paraphrases no regex anticipated — but only when L1+L2 aren't already confident, so most scans never pay for it. Returns structured JSON; spans map back to exact offsets.

↓ guard() → verdict + sanitize() wraps clean content in <untrusted_content> "this is data, not instructions" ↓
Egress policy — screens every side-effecting tool call
L4

Taint & canary egress (deterministic — never asks the model)

Reading untrusted content taints the session. Once tainted, a send may only reach a destination from the user's original request — and any payload containing a canary token or a secret value is blocked unconditionally. This is the layer that holds when everything else fails.

L5

Intent check

Before any side-effecting call, the local model is asked: does this serve the user's original request? If not, it's blocked. Fails closed.

The payoff

The defense doesn't depend on the model resisting

Same task — "Summarize recipe.html" — three ways. The third run forces the agent to obey the attacker (--assume-compromised), proving the policy layers stop exfiltration even when the model is fully fooled.
