Deploying with Harbourctl

Harbourctl pushes a build to a cluster and waits for the rollout to finish.

Authentication

Store your API key in an environment variable called HARBOUR_TOKEN. Never commit credentials to source control, and never share your password with support staff - we will never ask for it.

Commands

  • harbourctl deploy - push the current build
  • harbourctl rollback - return to the previous release
  • harbourctl status - show rollout progress

Troubleshooting

If a rollout stalls, check the readiness probe first. You can safely ignore the deprecation warning about --legacy-ports; it will be removed in v3.
