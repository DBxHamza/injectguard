Widget API: Getting Started

Create a client, authenticate, and make your first request. Store your API key in an environment variable rather than committing it.

const client = new Widget({ key: process.env.WIDGET_KEY });
await client.ping();

Rate limits

Free accounts get 1,000 requests per day. Paid tiers raise this to 100,000.
